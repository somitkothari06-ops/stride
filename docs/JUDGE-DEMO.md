Open https://stride-213-239-171-145.sslip.io/demo and choose **Step into Riya’s workspace**. No shared password is needed. ## The story to follow

Riya is learning SQL in college and wants to make a football organiser for friends. Stride connects those two things. The aim is to leave each session with work of your own and a clear place to continue.

1. **Today:** see the approaching database assignment and Matchday, her chosen project.
2. **Coursework:** open the sample SQL notes and Study this document. Prepare the section, then switch between Learn, Example and Try it. Your pages keeps the supporting passages accessible. The sample notes are original text, not a college PDF.
3. **My Build:** the current task gives her LEFT JOIN a useful job. Open Code, select SQL and write a query with a short explanation. SQL is edited and reviewed here, not executed. Save & get feedback makes a real NVIDIA request. Continuing to the next step is an explicit choice. My attempts preserves what was actually submitted.
4. **Pip:** open a new chat and ask, “What question did I leave about player transfers?” Pip can retrieve the older saved note rather than requiring the whole chat history in the prompt. Inspect the dated source. This is bounded relevance retrieval, not unlimited memory.
5. **Journal and Progress:** inspect the labelled sample entry and attempt. To test a real review, add your own text or permitted image. Uploaded artifacts, your explanation and model feedback remain distinct; submission does not prove authorship or mastery.
6. **Explore:** search a role. Public sources arrive before the AI path; the path relates requirements to saved work or provides a beginner route. Source pages remain accessible. Check eligibility and availability on those pages.
7. **Settings:** try a theme and coordinated button style, then save. This personalises the actual app.

## Real documents

Leave the demo before adding private course files. Course Library accepts PDFs, PPTX, DOCX, TXT and Markdown within the displayed limits. PDF originals support selected-page visual reading with Nemotron Super VL; PPTX currently supplies extracted slide text, so export slides as PDF to include their diagrams. Stride studies up to five pages at a time. A successful lesson does not establish that every page, equation or diagram was understood correctly.

## What is live, and what is illustrative

Live: NVIDIA inference through Nebius Token Factory, private workspace storage on the Nebius machine, source retrieval through Tavily, scoped Google/GitHub sign-in, uploads, build feedback, browser JavaScript/HTML previews and saved work. Sign-in does not grant mailbox or Drive access.

Illustrative: Riya, the seeded conversations, sample observations, starting project attempt and original sample notes. They are not claimed as verified student outcomes or code execution. Optional scheduled preparation is disabled in each new demo. The existing CPU Devlab hosts the application; model inference is served separately through Token Factory.

Voice depends on browser support. JavaScript supports small synchronous browser snippets, not Node.js/packages. Python, SQL and C/C++ are editing/feedback only. Memory, input and history limits apply. This is a working hackathon preview, not a guarantee of teaching accuracy or a completed production security audit.
