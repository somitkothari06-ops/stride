# Five independent design studies

Open `/design-lab/index.html` on the running preview. The user selected Signal (03) on October 25, 2026. The landing page, About You flow and working app now use that direction with larger text. The other designs remain independent studies.

| Direction | What changes | Preview |
|---|---|---|
| Paper Studio | Cream paper, warm rust, editorial serif headings, open reading layout | `/design-lab/paper.html` |
| Night Shift | Dark navy, cyan, technical labels, compact sidebar and work panels | `/design-lab/night.html` |
| Signal | Cobalt, yellow, large graphic type, top navigation and strong split panels | `/design-lab/signal.html` |
| Orbit | Lavender, peach, soft rounded forms and playful decorative shape | `/design-lab/orbit.html` |
| Margin | Black, ivory, small red accent, serif reading surface and narrow navigation rail | `/design-lab/mono.html` |

Each preview includes Today, a sample course library, Memory and a practice screen. Practice checks and file selection are local demonstrations only: no data is saved/uploaded and no AI call is made. The actual course-library implementation is in the main app and is documented separately.

Choose a whole direction, or identify specific elements to combine. These concepts are for visual comparison; their existence does not mean the production app has adopted a new theme or that full accessibility/phone QA has been completed.
